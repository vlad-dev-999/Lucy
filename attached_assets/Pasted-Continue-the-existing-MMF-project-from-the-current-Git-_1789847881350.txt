4. REVIEW ACTIONS
==================================================

Implement these actions against the existing data model:

- Merge
- Keep Separate
- Correct
- Retire
- Create Canonical
- Investigate

Rules:

MERGE
- require an explicit canonical target
- create/update lineage
- preserve every legacy record
- record reviewer/time/reason

KEEP SEPARATE
- do not merge anything
- record the decision
- preserve the review history

CORRECT
- preserve original legacy value
- update/create the appropriate canonical value
- record decision/reason

RETIRE
- never delete the source record
- change status appropriately
- preserve history

CREATE CANONICAL
- create a canonical item
- establish lineage where appropriate
- preserve the legacy record

INVESTIGATE
- leave unresolved
- record the decision/history

Do not silently alter or delete legacy source data.
